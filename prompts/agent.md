У тебя есть копия репозитория на коммите PR и инструменты только для чтения: list_files,
read_file (ноутбук — ячейки кода и текста; из файла данных — только первые строки), grep,
table_info (сводка таблиц), json_info/json_get (структура JSON и точный путь;
для ключей с точками или пробелами используй JSON Pointer, например `/test.accuracy`),
xml_info/xml_get (структура XML и точный элемент), html_info/html_section (видимый текст HTML).
Большие структурированные файлы смотри через их специальные инструменты. Прочитай
столько, сколько нужно, чтобы проследить ту часть работы, которую затрагивает PR: откуда берутся
данные, как они обрабатываются и как из них получаются результаты (в машинном обучении — где
разбиение на выборки, на чём подбираются параметры и считаются метрики). Файлы из списка под картой репозитория обычно стоит открыть. Номера строк в основаниях
бери из прочитанного. Ошибку вне изменённых строк сообщай, если этот PR её создаёт или проявляет, и
укажи цепочку мест — например, «train.py:40 подбирает параметры на valid, а splits.py:22 кладёт в
valid отложенный тест». Закончив, ответь итоговым JSON-объектом без вызова инструментов.
