# Как устроен сервис — схемы

Обновлено: 2026-10-18.

Шесть схем о том, из чего состоит ИИ-куратор, как проходит событие от коммита студента до
замечания в панели и что куратор помнит о проекте. Подробности и пометки «есть / нет» — в
`../сценарии/`; при расхождении верна детализированная концепция и код.

**Как смотреть и править.** Файлы `.drawio.svg` — обычные картинки (GitHub и любой
просмотрщик показывают их как есть) со встроенной схемой draw.io. Править: открыть файл в
[app.diagrams.net](https://app.diagrams.net) (Open → Device) или в VS Code с расширением
Draw.io Integration (`hediet.vscode-drawio`) и сохранить в тот же файл — формат сохранится.
Меняется поведение сервиса — схема правится в том же заходе, что и сценарии.

## 1. Архитектура

![Архитектура](01%20архитектура.drawio.svg)

- Один процесс Node.js (Next.js): приём вебхуков, очередь, разбор, полный обзор, панель и
  фоновые задачи живут вместе; отдельный процесс — только агент, и он видит лишь ключ модели.
- Всё состояние — один файл SQLite; модули ходят в него только через `lib/curator/store.ts`.
- Внешние зависимости: GitHub (организация `ai-chem-curator`, приложение `AI Chem Curator`),
  языковая модель через OpenAI-совместимый API (сейчас ИИ-роутер Selectel), CronBox для
  оповещения о сбоях.

## 2. Путь коммита

![Путь коммита](02%20путь%20коммита.drawio.svg)

- Вебхук отвечает сразу; разбор идёт в очереди по одной задаче, через 10 секунд после
  последнего коммита.
- Проверка «AI Curator» блокирует слияние, только пока идёт разбор, и не дольше 30 минут;
  находки слияние не блокируют.
- Сбой агента — запасной разбор по diff; лимит, бюджет или срок — «Не разобрано», задача
  продолжает попытки до 24 часов.

## 3. Жизненный цикл замечания

![Жизненный цикл замечания](03%20жизненный%20цикл%20замечания.drawio.svg)

- «Исправлено» ставится в два шага: модель видит исправление в PR — «ждёт слияния»; PR слит в
  основную ветку — «исправлено».
- Модель меняет только статус и причину; решения человека — в досье, с причиной.

## 4. Память и полный обзор

![Память и полный обзор](04%20память%20и%20полный%20обзор.drawio.svg)

- Память проекта — замечания и заметки о его устройстве; каждый разбор PR получает их в
  запросе.
- Полный обзор перечитывает основную ветку целиком при подключении, возобновлении, по кнопке и
  при разрыве памяти; обновляет заметки, issue «Обзор проекта» и коммит памяти.

## 5. Данные

![Данные](05%20данные.drawio.svg)

- Двенадцать таблиц; служебный PR с номером 0 хранит разборы полного обзора.
- Схема меняется миграциями по `PRAGMA user_version`.

## 6. Панель и комментарий в PR

![Панель и комментарий](06%20панель%20и%20комментарий.drawio.svg)

- Скриншоты панели сделаны на демо-данных, комментарий куратора — живой прогон на
  `ai-chem-curator/test`, PR #4.
- Обе роли видят одинаковые экраны с разной областью видимости.
