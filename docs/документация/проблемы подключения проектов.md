# Проблемы подключения проектов

Краткий список для последовательного обсуждения. Пункты 2–5 открыты. Подробности и источники — в
[обратной связи от 05.11.2026](обратная%20связь%20по%20подключению%20проектов%20%E2%80%94%202026-11-05.md).

1. **Приватные репозитории.** Принято решение использовать ревью без обязательной защиты ветки.
   Код можно передавать модели. Ревью последнего коммита приходит в PR даже после слияния.
   Осталась проверка на тестовом приватном репозитории.
2. **Переезд существующего проекта.** Нужен понятный способ перенести проект из другой
   организации с историей коммитов, ветками и тегами; отдельно определить, нужно ли
   сохранять старые PR и issues и у кого есть права на перенос.
3. **Подключение без шаблона.** Текущий интерфейс ведёт по сценарию создания нового
   репозитория. Нужно ясно показать путь для уже существующего проекта и проверять
   недостающие настройки, не заставляя переносить файлы вручную.
4. **Выбор модели.** Сейчас модель задаётся для всего сервиса. Нужно решить, нужен ли
   выбор по проекту, кто его делает и как ограничить стоимость и сохранить сопоставимость
   результатов.
5. **Проверка сценария на пользователях.** Подключение ещё не прошло пилот с будущими
   пользователями. Нужны тестовые репозитории, несколько волонтёров или студентов и
   фиксация шагов, на которых они застревают.

Разбирать пункты по одному; после решения обновлять его статус и записывать принятое
решение в `принятые решения.md`.
