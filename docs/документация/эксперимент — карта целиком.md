# Первоначальная карта одним запросом

Дата: 2026-11-21. Экспериментальная ветка `codex/initial-map-snapshot` создана от локальной версии `385c731`. Сервер не обновлялся.

Только первая задача с причиной `initial`, без прежних заметок и SHA памяти, использует новый путь. Последующие полные обзоры и PR сохраняют прежний маршрут. `INITIAL_OVERVIEW_MODE=agent` отключает эксперимент. Настройка `INITIAL_MAP_CONTEXT_TOKENS` задаёт доступное окно, по умолчанию 128000; вход оценивается по длине, это не точный токенизатор модели.

Программа скачивает архив закреплённого коммита и собирает полный текст отобранных файлов в блоки «путь / содержание». Используется существующая классификация `fileKind`: табличные данные, JSONL, логи, lock-файлы и сгенерированные файлы исключаются. Дополнительно исключаются служебные каталоги, файлы учётных данных, двоичные и графические форматы. `.pdbqt` исключается как формат молекулярных данных только в этом эксперименте: общий классификатор PR не меняется. Ноутбуки представлены всеми кодовыми и текстовыми ячейками без результатов исполнения и встроенных изображений.

Список переданных и исключённых файлов записывается в диагностику. Исходники не обрезаются. Неполная распаковка, нераспакованные допустимые материалы, слишком большой текст или превышение оценённого окна останавливают запрос до обращения к модели. Автоматического сжатия и инструментального продолжения нет.

Модель получает один запрос без инструментов: описать проект по прежней структуре notes (Суть, Карта репозитория, Путь данных, Сознательные решения). Для ненаучного проекта разделы описывают его реальный основной сценарий. Возвращаются summary, notes и пустой findings. Поиск ошибок и инструментальная перепроверка не выполняются. Неожиданные находки отклоняются. Разбор JSON, сохранение заметок, SHA памяти и подготовка публикации используют действующий маршрут. Резервный провайдер и ограниченное исправление синтаксиса JSON могут добавить запросы; нормальный успешный путь содержит один.

Проверки: `npx tsx scripts/initial-map-selftest.mts`, `npm run test:reliability`, `npm run test:reviews`, TypeScript, ESLint и production build. Тест сборщика проверяет полный 501-строчный файл без обрезки, отсутствие запрещённых данных, ячейки ноутбука и отказ до модели при переполнении.

Живой локальный тест запускается через `scripts/overview-queue-local.mts` в новой изолированной БД с пустой памятью. Запись в GitHub заменена заглушкой; это проверка процесса построения карты и очереди, но не пользовательской формы или реальной доставки issue.
