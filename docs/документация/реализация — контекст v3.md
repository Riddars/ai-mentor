## Этап 1

Новые модули: `context-size.ts`, `context-parts.ts`, `repository-inventory.ts`.
Манифест/представления на диске, UTF-8 диапазоны, детерминированный упаковщик,
проверка покрытия, повторное построение допущенного запроса по хешу.
Счётчик по умолчанию — оценка, не настоящий токенизатор модели; замена
счётчика предусмотрена интерфейсом и не меняет алгоритм упаковки.
Формат PR diff адаптируется отдельно на этапе 3; здесь проверяется общий
механизм и обычное текстовое представление. Существующий runtime не переключён.

Проверено: `npx tsx scripts/context-parts-selftest.mts` (49 частей, 40 Unicode
fixtures, побайтовое восстановление, BOM/CRLF/emoji, отсутствие потерь,
проверка подмены контекста, файловый манифест); TypeScript; целевой ESLint.

## Этап 2

`INITIAL_OVERVIEW_MODE=parts` включает новый путь; прежний режим пока остаётся
по умолчанию. Миграция SQLite22 сохраняет ответы частей. Большая карта
объединяется иерархически, формат проверяется, исправление JSON ограничено.
Политика исключения вынесена в независимый модуль. Данные передаются только
в виде формата/размера; `.env.example` — только имена настроек без значений.

Первое ревью судьи выявило ошибки стабильности ключа при retry, допуска
полностью сохранённого результата с малым остатком бюджета, размера
промежуточных описаний и окна резервной модели. Добавлены исправления и
регрессионные проверки: `map-pipeline-selftest.mts`, `map-queue-selftest.mts`.
Последний проверяет настоящий executeOverviewJob и SQLite с заглушенными
GitHub/LLM: прерывание, повтор, изменение режима/ручных notes между попытками.
Завершённая часть не отправляется повторно, ручные заметки сохраняются.
Счёт за все эти проверки — ноль: сеть заменена заглушками.

Дополнительные проверки второго gate: восстановление перепланированного
исследования с остатком 65000 (одна часть + сборка), перепланированного reducer
с остатком 50000 (одна часть + сборка), полностью сохранённого результата
с остатком 100 (ноль вызовов). План бюджета учитывает максимальные разрешённые
размеры будущих описаний и все уровни сборки; 10 файлов по 140000 символов
при недостаточном бюджете останавливаются ДО вызовов модели.
Судья самостоятельно повторил четыре suite `test:context` и TypeScript.
